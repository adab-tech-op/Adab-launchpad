# ADAB — Next.js 16

Premium heritage-fusion menswear storefront for **ADAB**, migrated from a
TanStack Start (Vite) app to **Next.js 16 (App Router)**. Functionality and
visual design are preserved 1:1.

## Stack

- **Next.js 16** (App Router, Turbopack) + **React 19**
- **Tailwind CSS v4** (`@tailwindcss/postcss`, `tw-animate-css`)
- **Supabase** (`@supabase/supabase-js`) — client-side reservation & waitlist inserts
- **sonner** (toasts), **zod** (validation), **lucide-react** (icons)
- **@tanstack/react-query** provider (kept from the original shell)

## Getting started

```bash
npm install
cp .env.example .env.local   # then fill in your Supabase values
npm run dev                  # http://localhost:3000
```

Production build:

```bash
npm run build && npm run start
```

## Environment variables

Set these in `.env.local` (see `.env.example`):

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Supabase publishable/anon key |
| `NEXT_PUBLIC_SITE_URL` | *(optional)* absolute base URL for `sitemap.xml` and OG metadata, e.g. `https://adab.co` |

The Supabase client only performs public, RLS-guarded `INSERT`s into
`reservations` and `waitlist_signups` (see `supabase/migrations/`). No service-role
key is used or needed.

## ⚠️ Three assets are hosted on Lovable and need localizing

The **logo**, **favicon**, and **desktop hero** existed in the original repo
only as Lovable `*.asset.json` pointer files (not real image binaries), so they
could not be bundled here. They are still referenced exactly as before, via
their `.url` fields, which point at Lovable-hosted paths (`/__l5e/assets-v1/...`).
**Those URLs will 404 when the site is deployed anywhere other than Lovable.**

To fix (once you have the real image files):

1. Drop the real files into `public/assets/`, e.g.
   `adab-logo.png`, `adab-favicon.png`, `hero-desktop.png`.
2. Update the references:
   - **Logo** — `src/components/site/SiteHeader.tsx`, `SiteFooter.tsx`,
     `MobileNavModal.tsx`: replace `logoAsset.url` with `"/assets/adab-logo.png"`
     (and remove the `logoAsset` import).
   - **Favicon** — `src/app/layout.tsx`: set `icons: { icon: "/assets/adab-favicon.png" }`.
   - **Desktop hero** — `src/app/page.tsx`: replace `heroDesktop.url` with
     `"/assets/hero-desktop.png"`.
3. You can then delete the `src/assets/*.asset.json` files.

All other images are real files already served from `public/assets/`.

## What changed from the TanStack Start original

- File-based routes (`src/routes/*`) → App Router (`src/app/**/page.tsx`).
- `head()` route option → Next Metadata API (`metadata` / `generateMetadata`).
- `@tanstack/react-router` `Link`/`useRouterState` → `next/link` / `usePathname`.
- Interactive pages split into a server `page.tsx` (metadata) + a `"use client"` child.
- Env vars `VITE_*` → `NEXT_PUBLIC_*`.
- Removed unused TanStack Start server scaffold (`server.ts`, `start.ts`,
  `router.tsx`, auth middleware) and ~49 unused shadcn/ui components (only the
  `sonner` toaster was in use). Behaviour is unchanged.
